# Miniature Tier Lab ($50-70K)

Balanced approach combining GPU workstations with **1-2 compact humanoid robots** (Unitree H1/G1) for hands-on Physical AI education. Most development in simulation, validation on real hardware.

## Budget Breakdown

| Component                          | Quantity | Unit Cost (USD) | Total Cost (USD) |
|------------------------------------|:--------:|----------------:|-----------------:|
| **Robots**                         |          |                 |                  |
| Unitree H1 Humanoid Robot          | 2        | $90,000         | $180,000         |
| **Compute**                        |          |                 |                  |
| GPU Workstation (RTX 4070)         | 3        | $3,500          | $10,500          |
| Workstation (CPU-only)             | 2        | $1,200          | $2,400           |
| **Infrastructure**                 |          |                 |                  |
| Safety Barriers (modular)          | 4        | $400            | $1,600           |
| Network Switch (10 GbE)            | 1        | $800            | $800             |
| Charging Station (custom)          | 2        | $600            | $1,200           |
| Tool Kit (maintenance)             | 1        | $500            | $500             |
| Monitors, peripherals              | 5 sets   | $300            | $1,500           |
| **Total Hardware**                 |          |                 | **$198,500**     |

**Software**: Same as Proxy Tier ($400/year)

**Typical Budget**: $50-70K assumes **institutional discounts** on Unitree robots (~50% off, $45K/robot) or purchasing 1 robot initially ($55K total).

## Space Requirements

**300-400 sq ft** with 10×10 ft robot operation zone, safety barriers, 6 ft clearance around robots.

## Strengths

✅ Real hardware manipulation and navigation
✅ Sim-to-real validation experimental
✅ Affordable vs. full-scale humanoids
✅ Industry-relevant project portfolios

## Limitations

❌ Compact robots: limited payload (3 kg), reach (0.6 m)
❌ Battery life: 1-2 hours (vs. 3-4 for full-scale)
❌ Smaller student capacity (10-12 due to robot access)

## Best For

Mid-sized universities, AI research labs, robotics minors
