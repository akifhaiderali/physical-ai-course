# Physical AI & Humanoid Robotics Course

Welcome to the comprehensive guide for Physical AI and Humanoid Robotics education. This resource is designed for robotics educators, curriculum designers, university program coordinators, and advanced students evaluating Physical AI curricula.

## About This Course

This course specification provides a complete framework for teaching Physical AI through four progressive modules:

- **Module 1: ROS 2 Fundamentals** - Robot Operating System architecture, navigation, and multi-robot systems
- **Module 2: Simulation Environments** - Gazebo and Unity for robotics simulation and visualization
- **Module 3: NVIDIA Isaac Sim** - Synthetic data generation and sim-to-real transfer
- **Module 4: Vision-Language-Action (VLA)** - Multimodal AI for robotic manipulation and task execution

The course culminates in a **capstone project** where students integrate all four modules to demonstrate autonomous task execution on humanoid robots using VLA-based control.

## Course Structure

### Learning Progression

The course follows a pedagogically-sound progression from foundational concepts to advanced integration:

1. **Foundation (Weeks 1-4)**: ROS 2 architecture, nodes, topics, services
2. **Simulation (Weeks 5-7)**: Gazebo and Unity for robotics simulation
3. **Advanced Simulation (Weeks 8-9)**: NVIDIA Isaac Sim and synthetic data
4. **AI Integration (Weeks 10-12)**: Vision-Language-Action models and robotic manipulation
5. **Capstone (Weeks 13-16)**: Integrated project demonstrating all modules

### Hands-On Learning

Each module includes:
- **Detailed exercises** with setup requirements, procedures, and assessment criteria
- **Code examples** for ROS 2, Gazebo, Unity, Isaac Sim, and VLA frameworks
- **Real-world applications** on humanoid robot platforms

### Lab Infrastructure

Three lab tier options accommodate varying budgets and institutional needs:

- **Proxy Tier ($10-20K)**: Simulation-only workstations for budget-constrained programs
- **Miniature Tier ($50-70K)**: GPU workstations + compact humanoid robots for hands-on learning
- **Premium Tier ($120-180K)**: Full-scale humanoid robots + research-grade infrastructure for flagship programs

## Prerequisites

Students should have:
- **Programming proficiency**: Python and C++ at undergraduate level
- **Robotics fundamentals**: Kinematics, sensors, actuators
- **Linux command-line**: Basic familiarity with terminal operations
- **Machine learning basics**: Neural networks, computer vision concepts

## Learning Outcomes

Upon completion, students will be able to:

1. **Design and implement** multi-node ROS 2 systems for robot control and communication
2. **Create and validate** robot simulations in Gazebo, Unity, and NVIDIA Isaac Sim
3. **Generate synthetic training data** for perception models using domain randomization
4. **Integrate vision-language-action models** with robot systems for natural language task execution
5. **Deploy and test** robot policies on physical humanoid platforms
6. **Evaluate sim-to-real transfer** performance and troubleshoot reality gap issues
